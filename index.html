PROJECT OVERVIEW

「綺麗にする」より、
「伝わる順番」をつくる。

製造業向けのAI予知保全ソリューションを題材に、課題提起から導入判断までを 営業先が理解しやすいストーリーへ再構成した営業資料の制作事例です。

INDUSTRY 製造業 / IoT / AI

設備保全・生産技術を想定したBtoB提案。

TARGET 工場長・製造部門長・保全部門・生産技術

現場責任者と意思決定者の双方を意識。

PURPOSE 新規提案 / 商談説明 / PoC獲得

比較検討から次のアクションへつなげる。

SCOPE 構成設計・原稿整理・図解・ビジュアル設計

営業ストーリーからデザインまで一貫制作。

From Insight to Action

資料の構成ストーリー

課題から導入まで、一貫したストーリーで「伝わる」資料に。

  1. 01課題現状を明確化
  2. 02原因要因を整理
  3. 03解決策AI予知保全
  4. 04効果メリット提示
  5. 05比較違いを整理
  6. 06導入ステップ提示
  7. 07事例具体化
  8. 08料金判断材料
制作のポイント KEY POINTS
01
営業視点の構成設計

相手の関心・課題に合わせて、伝わる順番でストーリーを設計。

02
専門内容をわかりやすく図解化

複雑な技術情報も、図・写真・比較で直感的に理解できるよう整理。

03
提案につながるデザイン

信頼感・先進性・分かりやすさを重視し、商談で使いやすい資料に。

01

Problem First

最初から機能を並べず、「設備停止」「属人点検」「保全負荷」という顧客課題から入る構成に。

02

Visualize Complexity

AI・IoTの専門的な仕組みを、写真・アイコン・フロー・比較表に置き換えて理解負荷を軽減。

03

Reduce Friction

他社比較、導入ステップ、PoC、料金まで先回りして提示し、社内検討時の疑問を減らす設計。
